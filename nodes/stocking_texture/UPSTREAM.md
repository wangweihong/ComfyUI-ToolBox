# Upstream provenance

Core algorithms are copied from [silvermoong/stocking-texture-tool](https://github.com/silvermoong/stocking-texture-tool),
MIT license, commit `ad4cc92de86021f20bedcf9de5b27ec0ae574184` (2026-10-09).
The original copyright and full license are retained in `LICENSE` next to this file.

Vendored files: `core/guide_fields.py`, `walls.py`, `coverage.py`, `tiles.py`, `knit.py`, `look.py`, `oily.py`.
`look.Scene` has one compatibility-preserving addition: an optional `seed` argument replacing the module constant
when constructing its random generators. Its default remains the upstream seed and draw order.
`core/i18n.py` is a ToolBox adapter, removing all desktop settings/catalog dependencies.

ComfyUI tensor conversion, guide serialization, preview routes, caches, local model adapters, UI and examples
are implemented by ComfyUI-ToolBox. Small/empty domains and mask-exterior pixel restoration are handled in the
adapter, rather than changing the vendored numerical algorithms.

Synthetic numerical regression fixtures in `tests/test_stocking_texture.py` adapt the pinned upstream's MIT-licensed
tests. Example artwork in `examples/stocking_texture/assets` is generated by this project's script and contains
no upstream or user illustration. The desktop server, installers, sessions and sample images are not vendored.

## Upstream capability update

The opt-in `upstream/` renderer is pinned to [`f74c8ac0190ec43b2cdfcb13db86f35a83283311`](https://github.com/silvermoong/stocking-texture-tool/commit/f74c8ac0190ec43b2cdfcb13db86f35a83283311).
It vendors `look.py`, `oily.py`, `knit.py`, `tiles.py`, `split.py`, `symmetry.py`, `trace.py`, and the guide reader/writer
from `psd_io.py` under the same retained MIT license. The latter omits the experimental texture PSD writer.
`upstream/guide_fields.py` re-exports the unchanged original solver; `upstream/i18n.py` adapts Chinese/English layer names.
The Scene seed addition is retained. PSD alpha extraction additionally clips layer bounds to the canvas.

The original `core/` renderer remains the default for compatibility. The new renderer supplies Coil, deliberate moiré
and revised glossy shading, selected by `renderer_version=upstream_f74c8ac`. Masks and occlusion gaps are adapted
by ToolBox; fill gaps never expand the output selection. Region editing, presets, disk drafts, soft float layers,
ComfyUI file nodes/routes and workflow examples are ToolBox integrations, rather than the desktop server.

## Layered material integration

The V2 effects schema, composable material nodes, ordered pattern/text handlers, region inheritance and split caches
are ToolBox additions. Both pinned renderers and their original numerical routines remain unchanged. V1 migration
retains its sampling arithmetic and ordering; V2 field sampling uses full-image derivatives for ROI previews.
The fixed DejaVu Sans Bold font and its license are retained; no external artwork, fonts or asset uploads are added.
