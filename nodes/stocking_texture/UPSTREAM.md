# Upstream provenance

Core algorithms are copied from [silvermoong/stocking-texture-tool](https://github.com/silvermoong/stocking-texture-tool),
MIT license, commit `ad4cc92de86021f20bedcf9de5b27ec0ae574184` (2026-10-09).
The original copyright and full license are retained in `LICENSE` next to this file.

Vendored files: `core/guide_fields.py`, `walls.py`, `coverage.py`, `tiles.py`, `knit.py`, `look.py`, `oily.py`.
`look.Scene` has one compatibility-preserving addition: an optional `seed` argument replacing the module constant
when constructing its random generators. Its default remains the upstream seed and draw order.
`core/i18n.py` is a ToolBox adapter, removing all desktop settings/catalog dependencies.

ComfyUI tensor conversion, guide serialization, preview routes, caches, local model adapters, UI and examples
are implemented by ComfyUI-ToolBox. Small/empty domains and mask-exterior pixel restoration are handled in the
adapter, rather than changing the vendored numerical algorithms.

Synthetic numerical regression fixtures in `tests/test_stocking_texture.py` adapt the pinned upstream's MIT-licensed
tests. Example artwork in `examples/stocking_texture/assets` is generated by this project's script and contains
no upstream or user illustration. Desktop/PSD exporters, installers, server, sessions and sample images are not vendored.
