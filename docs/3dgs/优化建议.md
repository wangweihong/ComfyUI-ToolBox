# 优化建议与验证顺序

本页记录讨论过的下一轮方案，**尚未执行这些优化对照**，不沿用本机原始测试的质量结论。现有结果见[测试报告](本地测试报告.md)。

| 优先级 | 当前问题 | 计划与验证方法 |
| --- | --- | --- |
| 高 | 提灯组的包、桌面和背景关系变化 | 先测试单个主体、较小环绕角度和不同生成种子；筛掉物体位移、形变及重复视角明显的视频，再做SfM。分段360°需要重叠视角和一致结构，不能仅拼接两段就假设几何一致。 |
| 高 | 宇航员背景雾状高斯 | 增加跨帧稳定的主体遮罩，对比全场景与仅主体训练。关注头发、手指和头盔边界，避免遮罩闪烁污染训练。 |
| 高 | 上半身截断区域的放射状漂浮 | 完整身体需求改用完整参考图；半身展示则保留原始PLY，另导出清理、裁切版。检查俯视和下方视角，不能只挑正面图验收。 |
| 高 | 70/70注册仍可能是错误轨迹 | 在训练前检查相机轨迹跳跃、异常三维点与重投影误差。提灯最大相邻位移约为中位数的27.5倍，应作为异常样例；具体阈值需要用更多样本验证。 |
| 中 | 全局SfM受异常匹配与焦距估计影响 | 在完全相同帧集上比较global与incremental，并检查共享焦距是否合理。分别记录注册率、轨迹和渲染质量。 |
| 中 | 5000步可能不足以收敛细节 | 仅对几何合格的数据比较5000、15000、30000步；相同输入、遮罩和评估集。记录高斯数量、耗时和新视角质量，不能只比较PSNR。 |
| 中 | 9张留出图仍有邻近训练帧 | 增加连续角度区间留出，导出真正的3D高斯转台视频；明确所有帧已参与SfM，未得到独立实拍真值。 |
| 中 | 工作流便利性 | 预设更合适的初始预览相机、增加轨迹异常提示、在训练结束后汇总输出路径；保留失败日志和独立运行目录。 |

下一轮优先做宇航员的“稳定遮罩训练＋漂浮清理”，随后重做提灯源视频。提高训练步数或高斯上限不能保证修复相互矛盾的多视角观测。

参考：[COLMAP重建选项与方法](https://colmap.github.io/faq.html)、[Brush透明图与遮罩支持](https://github.com/ArthurBrussee/brush#training)。
