# 技术分析与复现范围

H3根据单张参考图推断未见视角，首末帧同图帮助闭环；PyCOLMAP4.2.1通过SIFT匹配、共享SIMPLE_PINHOLE内参和SfM估计相机与稀疏点云；Brush0.3.0通过多视角可微渲染训练高斯模型。

原帖使用MiniMax、COLMAP及Brush/Postshot。本镜像复用ComfyUI原生H3和已有Orbit LoRA，使用自带Linux节点调用PyCOLMAP的global_mapping（已合入的GLOMAP算法）或incremental_mapping。没有安装Enndee整包、独立COLMAP GUI或GLOMAP命令。

当前PyCOLMAP wheel为CPU实现，Brush通过Vulkan执行训练。通用Vulkan Loader在镜像内，显卡设备驱动由实际环境提供；镜像不包含显卡厂商驱动或固定ICD配置。

首末闭环、全部相机注册、PLY导出成功都不能证明几何真实。背景/主体变化会污染匹配与训练；单张图补出的背面没有实拍真值。PLY是高斯外观表示，不是自动获得骨骼、UV和封闭拓扑的网格。
