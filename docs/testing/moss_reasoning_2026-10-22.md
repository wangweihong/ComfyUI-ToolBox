# MOSS 推理开关修复与验证（2026-10-22）

## 修复

参考图路径原先只传递reasoning_budget，未向MTMD模板传递enable_thinking；Gemma4模板因此始终使用关闭思考的分支。现在on/off明确设置模板变量，auto保留处理器默认配置；已有模板参数在结束或异常时恢复。不支持此参数通道的视觉处理器在请求on时明确报错，避免静默忽略开关。

Gemma4原生thought通道与普通think标签分别解析，推理输出到REASONING，最终JSON进入校验和MOSS编译路径。支持文本模板预填的推理开始标记；未闭合的推理会报错，避免把推理中的JSON示例当成最终描述。关闭流、恢复模板参数和清除原生中断回调均在finally中执行。

节点类型、输入顺序、六个输出及工作流默认参数保持不变。没有改动篇幅预设，也没有自动开启思考或安装新依赖。
