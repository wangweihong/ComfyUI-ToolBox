## 实际队列与模型

五份功能工作流均通过 ComfyUI API 队列：手工、SAM3＋原有点选、深度、五样式比较、图层/诊断。
五样式在当前图片均产生实际变化。03 的最终示例包含两张 LoadImage 和 ImageBatch，深度输入也来自相同批次。

混合批次（空白图＋丝袜图片）：第一张报告无目标，第二张成功，输出批次为 1，成功输出索引为 0，
输入索引为 1。全空白批次产生明确错误，没有 PreviewImage 输出；原图不会作为成品输出。

SAM3 CUDA 识别到 1 个部位，分数约 0.72，冷推理约 1.05 秒。
原有 ViT-B CUDA 点选返回面积排序的三候选，实际点击约 0.71 秒，完成后模型回到 CPU。
SAM3 CPU 实际推理成功，识别到 1 个部位，分数约 0.69，约 15.82 秒。

当前 Easy-Sam3 解码器的普通坐标缓存预先分配在 CUDA 上，Module.to 无法迁移它们。
适配器使用 ComfyUI ModelPatcher 临时对齐缓存设备，退出和异常时恢复，不修改 Easy-Sam3 源码。
CPU 推理是在本测试机上验证的；该版本 Easy-Sam3 加载器初始化仍有 CUDA 依赖，不能据此宣称它在无 CUDA 的机器上可加载。
无模型的画笔/外部 MASK 核心处理不依赖 SAM3。
